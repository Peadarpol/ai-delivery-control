# AI Delivery Control

Production-grade agent harness and quality gates extracted from the GymBase platform. Standardizes multi-layer rules, AST static boundaries, and passive session outcome tracking.

## Quick Install

```bash
git clone https://github.com/Peadarpol/ai-delivery-control
python bootstrap/install.py --project-path /path/to/your/project
```

Full documentation: [docs/getting-started.md](docs/getting-started.md)

## Reference Implementation
Built and validated building [GymBase](https://github.com/Peadarpol/gym-management-system) —
a multi-tenant SaaS gym management platform.

## Status
Production-ready for solo developers and small teams (Tier 1).
Multi-machine and team features (Tier 2) in active development.
