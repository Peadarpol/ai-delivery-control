# Python FastAPI Stack Pack

Expert rules and guidelines for developing and verifying Python backend applications powered by FastAPI, Pydantic, SQLAlchemy, and pytest.

---

## 1. Route Handlers and Dependency Injection
- **Modular Routing**: Use `APIRouter` to structure modular endpoints by domain resource.
- **Route Functions**: Endpoints doing database or network I/O must be declared using `async def`.
- **Dependency Injection**: Use FastAPI's native dependency injection (`Depends()`) for cross-cutting logic (e.g. database sessions, authentication, config access).
- **Separation of Concerns**: Keep route handlers lightweight. Router functions must only parse inputs, call core service logic, and return responses. Avoid writing direct SQL or business calculations in routers.

---

## 2. Pydantic Models & Schemas
- **Request Validation**: Use Pydantic models to validate request bodies and query/path parameters.
- **Explicit Responses**: Always declare a `response_model` on endpoints or use concrete Pydantic models as response types. Never return raw Python dicts.
- **Mass Assignment Protection**: All input schemas (`*Create`, `*Update` request bodies) must set:
  ```python
  model_config = {"extra": "forbid"}
  ```
  to prevent property/argument injection vulnerability.
- **Field Constraints**: Leverage Pydantic's `Field` and annotations to validate range limits, string lengths, and formats (e.g. email, UUID) early.

---

## 3. SQLAlchemy Async Session Patterns
- **Async Database Driver**: Use async drivers (e.g., `postgresql+asyncpg` or `sqlite+aiosqlite`).
- **Session Lifecycle**: Use `async_sessionmaker` and manage session lifecycles using context managers or FastAPI dependencies to ensure connection pooling works correctly.
- **Async Execution**: Execute database statements using `await session.execute(stmt)`.
- **N+1 Prevention**: Explicitly load related entities using `selectinload` or `joinedload` inside queries to prevent N+1 lazy loading roundtrips.

---

## 4. Alembic Migration Conventions
- **Autogeneration Safety**: Always review autogenerated migration scripts. Ensure indexes, unique constraints, and foreign keys are explicitly named.
- **Reversibility**: Every migration must implement a functional `downgrade()` script.
- **Idempotency**: Add safe execution guards (e.g. `if_exists` / `if_not_exists`) for raw SQL statements.
- **Data Preservation**: Add column modifications with fallback defaults for populated tables to prevent server startup crashes.

---

## 5. pytest-asyncio and Route Testing
- **Fixture Scoping**: Use `pytest_asyncio.fixture` with appropriate scoping (typically `function` or `session`).
- **Async Tests**: Declare test functions utilizing async features using `async def` and annotate with `@pytest.mark.asyncio`.
- **API Client**: Utilize `httpx.AsyncClient` or FastAPI's `TestClient` to mock API routes and verify status codes, header responses, and JSON structures.
- **Database Rollback**: Wrap integration tests in transactions that roll back automatically after each test execution to ensure test state isolation.

---

## 6. Background Task Handling
- **Non-blocking Operations**: Use FastAPI's native `BackgroundTasks` for lightweight post-request processing (e.g. sending notification emails, publishing event messages).
- **Async Callbacks**: Declare background tasks as `async def` and inject them into endpoints.
- **Resource Scope**: Ensure background tasks open their own database sessions if needed, since the request-scoped database session might close before the task completes.
