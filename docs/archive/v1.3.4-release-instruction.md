the threshold bug (HIB-DREAM-03) means projects without escalated sessions can never
produce proposals regardless of FAIL frequency. GymBase had 17 FAILs across 79 sessions
and produced zero proposals.

Fixing all three is higher priority than any other item in this release.

### HIB-DREAM-03: escalation_rate threshold redesign

**File**: `.agent/scripts/distill_dream.py`, lines ~399–402

**Current logic** (the `AND` is the bug):
```python
is_flagged = (
    count >= 3 and escalation_rate >= 0.40 and appearance_rate >= 0.20
) or max_severity == "CRITICAL"
```

`escalated` outcomes require a HALT file or `halt_event` in `harness_events.jsonl`.
Projects operating normally have `escalated_count = 0` permanently, so
`escalation_rate = 0.0` regardless of FAIL frequency. The `AND` makes the threshold
permanently unmet for any well-functioning project.

**New logic** — change `AND` to `OR` between the rate conditions:
```python
is_flagged = (
    count >= 3
    and (appearance_rate >= 0.20 or escalation_rate >= 0.40)
) or max_severity == "CRITICAL"
```

A pattern now qualifies if:
- It appears in ≥20% of sessions within 30 days (frequent enough to matter), OR
- 40% of its sessions escalated (a severity signal), OR
- A single CRITICAL event occurred (unchanged bypass path)

**Do NOT implement fractional weighting** for `partial` and `abandoned` outcomes
in this release. This is a more complex change that requires separate validation.
Add it to the backlog as HIB-DREAM-03a for a future release — update the backlog
entry before closing this sprint.

The `OR max_severity == "CRITICAL"` bypass path is correct and must not change.

**Update docs/harness-health.md**: In the "Dream Phase Threshold Logic" section
created in Wave 0a, document the revised formula, the rationale (projects without

```python
def report_dream_proposal_staleness():
    section_header("DREAM PROPOSAL STALENESS")
    proposals_dir = Path(".agent/state/dream_proposals")
    if not proposals_dir.exists():
        print("  Status         : NO PROPOSALS DIR")
        return

    warn_days = 30      # config: dream_proposals.staleness_warn_days
    critical_days = 90  # config: dream_proposals.staleness_critical_days
    max_open = 10       # config: dream_proposals.max_open_proposals

    open_proposals = sorted(proposals_dir.glob("*__open.md"))
    if not open_proposals:
        print("  Status         : \033[92mCLEAN (no open proposals)\033[0m")
        return

    now = datetime.datetime.now(datetime.timezone.utc).replace(tzinfo=None)
    stale_warn, stale_critical = [], []

    for p in open_proposals:
        try:
            content = p.read_text(encoding="utf-8")
            match = re.search(r"Generated:\s*(\d{4}-\d{2}-\d{2})", content)
            if not match:
                continue
            generated = datetime.datetime.strptime(match.group(1), "%Y-%m-%d")
            age_days = (now - generated).days
            if age_days >= critical_days:
                stale_critical.append((p.name, age_days))
            elif age_days >= warn_days:
                stale_warn.append((p.name, age_days))
        except Exception:
            continue

    print(f"  Open proposals : {len(open_proposals)}")
    if len(open_proposals) > max_open:
        print(f"  \033[93m⚠ WARN: {len(open_proposals)} proposals exceeds max ({max_open})\033[0m")
    for name, age in stale_critical:
        print(f"  \033[91mCRITICAL: {name} — {age}d old (>{critical_days}d threshold)\033[0m")
    for name, age in stale_warn:
        print(f"  \033[93mWARN: {name} — {age}d old (>{warn_days}d threshold)\033[0m")
    if not stale_warn and not stale_critical:
        print(f"  Status         : \033[92mHEALTHY (all within {warn_days}d)\033[0m")
```

### T1-L-01a — Spec collision detection

**File**: `.agent/scripts/check_spec.py`

Add `_check_spec_collision(spec_id, spec_path, specs_dir, threshold=0.4)` using
stdlib only (`re`, `pathlib`, `collections`). After Pass 1 structural checks pass,
compute Jaccard similarity of acceptance criteria keywords against all APPROVED and
DRAFT specs in `specs_dir`.

```python
def _check_spec_collision(spec_id, spec_path, specs_dir, threshold=0.4):
    def extract_criteria_keywords(path):
        content = path.read_text(encoding="utf-8")
        match = re.search(
            r"##\s+Acceptance Criteria\s*\n(.*?)(?=\n##|\Z)",
            content, re.DOTALL | re.IGNORECASE
        )
        if not match:
            return set()
        text = match.group(1).lower()
        words = re.findall(r"\b[a-z]{4,}\b", text)
        stopwords = {"must", "shall", "should", "will", "that", "with", "this",
                     "when", "then", "given", "and", "the", "for", "are", "not"}
        return {w for w in words if w not in stopwords}

    target_kw = extract_criteria_keywords(spec_path)
    if not target_kw:
        return []

    collisions = []
    for other in specs_dir.glob("SPEC-*.md"):
        if other == spec_path:
            continue
        other_content = other.read_text(encoding="utf-8")
        status = re.search(r"status:\s*(\w+)", other_content, re.IGNORECASE)
        if not status or status.group(1).upper() not in ("APPROVED", "DRAFT"):
            continue
        other_kw = extract_criteria_keywords(other)
        if not other_kw:
            continue
        intersection = len(target_kw & other_kw)
        union = len(target_kw | other_kw)
        if union > 0 and intersection / union >= threshold:
            collisions.append((other.stem, intersection / union))

    return sorted(collisions, key=lambda x: x[1], reverse=True)
```

def _create_session_checkpoint(session_id: str) -> None:
    """Create a recoverable git stash at session start. Non-fatal if stash fails."""
    try:
        result = subprocess.run(
            ["git", "stash", "push", "--include-untracked",
             "-m", f"AUTO: session-start checkpoint [{session_id[:12]}]"],
            capture_output=True, text=True, timeout=30
        )
        if result.returncode == 0 and "No local changes" not in result.stdout:
            print(f"[SESSION] Checkpoint created: git stash (session {session_id[:12]})")
    except Exception:
        pass  # Non-fatal — checkpoint is a safety net, not a requirement
